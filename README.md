# Lumélia — boutique one-product (culotte gainante post-partum)

Site statique (HTML / CSS / JS, sans dépendance). Ouvrez `index.html` dans le navigateur.

## À personnaliser
- **Nom de marque** : « Lumélia » est un nom provisoire, remplacez-le partout (`index.html`).
- **Photos** : remplacez les fichiers de `images/` par vos photos (mêmes noms, ou modifiez `GALLERY` dans `js/main.js`).
- **Prix, packs, date de fin d'offre** : bloc `CONFIG` en haut de `js/main.js`.
- **Avis** : tableau `REVIEWS` dans `js/main.js` — uniquement de vrais avis clients.
- **Guide des tailles, composition, délais** : textes dans `index.html`.
- **Paiement** : le bouton « Commander » est à brancher sur Shopify / Stripe Checkout.
